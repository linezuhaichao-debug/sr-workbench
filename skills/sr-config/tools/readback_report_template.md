# 读回验收报告模板（readback_report.md）

> sr-config skill 附带。每次写入工作簿后的验收报告**必须**逐条对照本模板，
> 每项标注 `pass | fail | not_applicable`（附证据定位），缺项或 `not_run` 一律按 `fail` 计。
> **禁止自拟另一套"全部通过"式清单替代本模板**——验收项以模板为准逐条映射，
> `pass` 的总数再多，也不能替代任何一项必达的 `fail`/缺失。
> 写入一律经 Excel COM（`tools/excel_com_edit.py`）；本报告的每一行都要能对到
> 引擎的机器可读证据 `*_验收报告.json`（V1–V7 + 追加记录的 V1c/V5c + 退出核对）。

## 报告头

- 任务分支：create_workbook | schema_change | record_change
- 目标文件：绝对路径（含 sha256）
- 源文件/来源文档：路径 + sha256（无则写"无"）
- **写入计划**：`plan.json` 路径 + change_set_id + op 条数（每条 op 的 change_id 与 change set 对得上）
- 备份文件：路径（新建文件写"无（新建）"）
- 写入引擎运行记录：`excel_com_edit.py` 的 `--json` 结果路径 · 退出码 · 预检结果
- **引擎验收报告**：`*_验收报告.json` 路径（原始证据，须一并交出）
- 报告生成时间与生成方式（脚本名或人工核对）

## 归一化痕迹如实记录（WARN 不是"通过"，但不判 fail）

Excel 自己保存的固有痕迹，实测六类。**逐类写清条数**（来自 `*_验收报告.json` 的 `checks`/`diffs`），
不要合并成一句"有少量归一化"，也不要把它们当作失败：

| # | 类 | 本表实际 | 说明 |
| --- | --- | --- | --- |
| N1 | 打印设置被写成显式默认值（V1b） | | 有效打印设置没变 |
| N2 | 主题色色阶尾数 / 字体 family·charset 被重算（V5b，条数 + 涉及哪些表） | | 可见属性逐项一致，渲染不可见 |
| N3 | VBA 存储被重新序列化（V6） | | 同大小、同流名；不逐字节比 |
| N4 | 未覆盖部件（图表/图片/切片器/批注用 VML 等，V7） | | 如实列出，不做语义比对 |
| N5 | **追加记录的行/列增长（V1c）** | | `max_row`/`max_col` 只允许增长、且增长全在声明区域内；条数与 before → after 要写出来 |
| N6 | **追加行新增的默认样式（V5c）** | | 声明写入的空白格被 Excel 补默认样式；逐格条数要写出来 |

## 报告里必须写清的两件事

- **重算口径**：默认零重算（除声明格与写入的公式格外，缓存值一律不动）。若本次用了 `--recalc` / `"recalc": true`，
  必须逐格列出"缓存值发生变化的公式格"（before → after），并说明为什么需要重算。
- **下游公式提醒**：引擎会列出"改动格被哪些公式引用"。零重算下这些公式的缓存值**没有**刷新 ——
  要么明确接受（并写进报告），要么改用 `--recalc` 重来一遍。

## 结论

- 状态：PASS（全部必达 pass 且无 open blocker） / BLOCKED（任一 fail）
- blocker 清单：编号 / 摘要 / 影响的 change / 恢复方式（备份路径或 `.failed.` 产物）
- deferred 清单：编号 / 摘要 / 是否影响已写入数据正确性（必须为否）
- 未覆盖范围声明（照抄 `*_验收报告.json` 的 `uncovered`；"工具执行成功"≠"验收成功"）
