# SR 系列技能 · 使用说明

sr 策划工作流技能：从头脑风暴一路走到正式 UE 回写。一个功能一个目录。

## 主线

从头脑风暴走到正式 UE 回写。这是推荐顺序，但全部 skill 也都可以单独调用。

1. 头脑风暴：竞品分析 `/sr-analysis` · 问答式访谈 `/sr-concept` · 旧文档分析 · 人工补充；
2. 成稿：`/sr-gdd-human` 出成稿 —— 只有纯规则与界面（零配置指代），期间可以反复改。
3. 配置与线框图（可选）：
   - 配置表：`/sr-config` 从成稿的规则生成配置表字段与记录。
   - 线框图：把成稿里的 ASCII 界面换成线框图：没有对应技能，可人工调用figmaMCP生成；替换 UI 可能带来功能改动。
4. 定稿：`/sr-gdd-ai` 把成稿 + 配置表综合整合成定稿（功能规则、界面、配置契约、多语言文本、验收标准），并据定稿列出多语言文本条目；
5. 定稿之后仍然可以改 —— 改走 `/sr-gdd-fix`（涉及配置表就调 `/sr-config` 改表并同步对应行）。主线定稿通过后状态为 `active`、成稿归档。
6. 正式 UE 回写：把定稿真正落到工程里 —— 没有对应技能，人工做。

## 旁支（不在主线上，需要时单独用）

| 技能 | 什么时候用 |
| --- | --- |
| `/sr-gdd-html` | 把定稿重排成评审会用的**单文件宣讲 HTML**。 |
| `/sr-gtgenerator` | GID 类型与多语言文本的增删改、翻译合并、导出，可根据定稿多语言文本条目直接添加 |
| `/sr-gdd-review` | 定稿审查，只读出报告。主线里由 `/sr-gdd-ai` 自动带上；**改完定稿要复审**时才单独用 |

## skill 一览

| skill | 干什么 | 关键产出 |
| --- | --- | --- |
| `sr-concept` | 一句话创意 → 设计核候选报告 → 你拍板 → 完整功能设计 | 设计稿（`analysis\`） |
| `sr-analysis` | 录屏/截图/PV 素材 → 证据链分析报告 → 你判定 → 复刻规格 | 分析报告 / 复刻规格（`analysis\`） |
| `sr-gdd-human` | 把入口产出落成**成稿**：只有纯规则与设计，决策留痕在附录 A，供你审核 | 成稿（`gdd\`） |
| `sr-config` | 从成稿规则**派生**配置字段与记录，最小事务写入，读回验收 | 配置工作簿（`gdd\`） |
| `sr-gdd-ai` | 把成稿 + 配置表**整合成定稿**：程序可实现的粒度，含配置契约与多语言文本条目 | 定稿（`gdd\`） |
| `sr-gdd-fix` | 定稿通过后的**唯一改动入口**：影响面扫描 + 最小编辑 + 决策记录 | 定稿原地更新 |
| `sr-gdd-html` | 把定稿重排成评审会用的**单文件宣讲 HTML**（用户手动触发） | 宣讲稿（`gdd\`） |
| `sr-gtgenerator` | GID 类型与多语言文本的增删改、翻译合并、导出 string_zh_CN 等 | `gtypes.xml` / `normaltxt.xml` |

## 术语

| 名词 | 是什么 | 谁产出 |
| --- | --- | --- |
| **成稿** | 只有纯规则与界面（零配置指代）给用户审阅；定稿通过后归档 | `/sr-gdd-human` |
| **定稿** | 主线路径整合出的**最终交付物**，通过后是**唯一的活文档** | `/sr-gdd-ai` |

## 产出落在哪

每个功能的工作全部落在 `<功能目录>` = `<SR_WORKSPACE>\features\<主题>\` 这一个目录里（从策划工作台进入的会话，工作目录就是它）。产物按"谁产生 / 给谁看"落进 4 个桶：

| 桶 | 装什么 | 典型产出 |
| --- | --- | --- |
| `evidence\` | 进来的原件 + 过程证据 | 竞品截图/录屏/PV · 旧文档原件 · 外部交付包 · 抽帧与证据包 · 校准流水 |
| `analysis\` | 想出来的内容 | 设计核三角报告 · 功能设计稿 · 体验报告 · 问题卡 · 复刻规格 · 各类交接 JSON · 旧文档分析 · 人工补充 |
| `gdd\` | 写出来的正文与交付物 | 成稿 · 定稿 · 修订点清单 · 审查报告 · 评审宣讲 HTML |
| `decisions\` | 定下来的事 | `决策记录.md` —— 一个功能只有一个决策文件，所有决策按时间追加 |
