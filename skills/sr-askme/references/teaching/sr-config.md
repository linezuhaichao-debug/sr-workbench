# sr-config 使用卡：策划规则落配置数据

**职责**：把 `sr-gdd-human` 成稿的规则**派生**成配置表字段与记录（新建运行时表 / 增删改字段 / 增删改记录），可追溯、可读回验收。改的是配置表本身；**若该功能已有定稿，改完顺手同步定稿 §4 的字段对应与 §6 配置契约**（最小编辑，不重跑整合、不过门）。

**什么时候用**："把这条规则落成配置表"、"给这张表加个字段"、"建一张新配置表"。

**怎么用**：

```
/sr-config 给英雄基础表加一个"碎片合成所需数量"字段
/sr-config 新建一张神话宝库里程碑表
```

**改表规则（硬要求）**：写入一律经 **Excel COM**（让本机 Excel 自己打开-改-存-退）——
**只改你要的单元格/区域**（别的格子一个都不动）、**批注/公式/格式/缓存值全部保留**、**改完保存并彻底退出 Excel**；
`openpyxl` 只用来读（探查 / 读回 / 比对），**不许写表**。验收会证明这三条（全表差异 ⊆ 声明区域 + 保真判据 + Excel 退出核对），验收不过不算改完。

**产出**：**新建的运行时表落 `<功能目录>\gdd\<表名>.xlsx`（不直接进 `config_root`，需你手动放过去）**；change set 与读回验收报告也在 `<功能目录>\gdd\`；**改既有表**时在 `config_root` 就地更新 + 同目录 `<表名>.backup.<时间戳>` 备份。已有定稿时另回写定稿 §4 / §6 对应行。
