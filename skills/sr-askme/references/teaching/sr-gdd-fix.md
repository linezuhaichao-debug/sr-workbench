# sr-gdd-fix 使用卡：功能 GDD 定稿修改

**职责**：定稿的**改动入口**——接头部 `doc_type: final_gdd` 且 `status` 为 `active`（已生效定稿）或 `pending`（定稿门之前的门内迭代）的已有定稿，按共用撰写纪律（`../gdd-writing-discipline.md`，按适用列取用）改规则、界面、范围、验收、配置对应与多语言文本；先做影响面扫描再最小编辑，不重跑整合。需要动配置表时调 `/sr-config`（后者改完顺手回写定稿 §4 / §6）。`pending` 时改完仍要回 `/sr-gdd-ai` 的定稿门。

**什么时候用**："改定稿"、"修订定稿"、"调一下定稿里的某处"、"定稿里这个规则要改成…"。

**怎么用**：

```
/sr-gdd-fix 把神话宝库定稿里每日次数从 3 次改成 5 次
```

**产出**（本功能目录 `<功能目录>\` 下）：定稿**原地更新**（`gdd\AI读版策划案_<功能名>_正式版.md` —— **不带日期**，维持唯一活文档；改之前先按 `../version-history.md` 存一版 `AI读版策划案_<功能名>_正式版_<日期>_<序号>.md`）；正文内联图片放 `gdd\assets\images\`；改动清单**不单独落盘**，要点写进 `decisions\决策记录.md` 那一条的正文。
