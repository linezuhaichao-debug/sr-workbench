# sr-gdd-html 使用卡：宣讲稿 HTML

**职责**：把功能 GDD **定稿整份**（§1–§11）出成一份**宣讲稿**（单文件 HTML）——开会 / 评审投屏，或直接发给人读：分节成页、表格与流程图示化、左侧目录可跳转、明暗主题可切、页内可搜索，截图 base64 内嵌、零外链。**只换读法，不改内容**：规则、数值、契约、验收全部来自源定稿。

**什么时候用**（**手动调用**——本 skill 是用户调用型，agent 不会自动接手）："把定稿出成宣讲稿 / 开会用的一版"、"这份定稿太密了，出一版宣讲稿"。

**怎么用**：

```
/sr-gdd-html <功能目录>\gdd\AI读版策划案_英雄升级功能优化_正式版.md
```

**产出**（本功能目录 `<功能目录>\gdd\`）：`<主题>_宣讲.html`（交付物）+ `<主题>_宣讲.md`（草稿，也是 `am patch` 局部改的源）成对留档；出口拍板追加一条 `decisions\决策记录.md`。

**与 `/sr-gdd-ue` 的分工**：本 skill 出**定稿全貌的宣讲稿**（谁都能读）；要**只讲界面**给 UE/UI 同事看，走 `/sr-gdd-ue`（出 `_UE.html`）。
