# sr-gdd-ue 使用卡：界面 UE 规则 HTML

**职责**：把功能 GDD **定稿的 §5**（用户体验与界面流程）重排成给 UE/UI 同事看的单文件 HTML——一个界面一节、左图右文、UE 规则按控件块化，截图 base64 内嵌、零外链，可直接外发。**只出 §5**：§1–§4 与 §6–§11 一律不进。只搬运不发明，且定稿要有界面清单。

**什么时候用**（**手动调用**——本 skill 是用户调用型，agent 不会自动接手）："把定稿的界面部分出成给 UE 看的 HTML"、"出一版界面规则图册给做界面的同事"。

**怎么用**：

```
/sr-gdd-ue <功能目录>\gdd\英雄升级功能优化_定稿.md
```

**产出**（本功能目录 `<功能目录>\gdd\`）：`<主题>_UE.html`（交付物）+ `<主题>_UE.content.json`（可复跑源）成对留档；出口拍板追加一条 `decisions\决策记录.md`。

**与 `/sr-gdd-html` 的分工**：本 skill 只出**界面与交互规则**（UE/UI 同事照着做界面）；要**定稿全貌**的宣讲稿走 `/sr-gdd-html`（出 `_宣讲.html`）。
