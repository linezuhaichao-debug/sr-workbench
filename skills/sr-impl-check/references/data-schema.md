# 对照页数据格式

渲染命令：

```bash
node "<SKILL_DIR>/scripts/build-check-page.mjs" --data check.json --out 页面.html
node "<SKILL_DIR>/scripts/build-check-page.mjs" --data check.json --check   # 只自检
node "<SKILL_DIR>/scripts/build-check-page.mjs" --print-schema              # 打印本格式
node "<SKILL_DIR>/scripts/extract-check-data.mjs" --from 页面.html --out check.json   # 从页面取回数据
```

## 顶层

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `slug` | 是 | localStorage 键前缀（`slug + '-v1'`）。**同一功能重渲染要沿用同一个 slug**，否则用户的核验勾选会丢 |
| `title` | 是 | 主标题 |
| `titleEm` | 否 | 标题后缀，重点色（如「违反的那条需求」） |
| `lede` | 否 | 结论一句话。支持 `**加粗**` 与 `` `代码` `` |
| `meta` | 否 | 头部信息键值对，建议固定 4 项：需求包 / 需求文档 / 工程 / 日期 |
| `issues` | 是 | 问题与通过项数组，见下 |
| `spec` | 建议 | 需求清单：`{ "A": ["节标题", "编号|标题\n编号|标题"] }` |
| `footer` | 否 | 口径说明若干条，支持 `**加粗**` |

## issues[]

| 字段 | 必填 | 写法 |
| --- | --- | --- |
| `id` | 是 | 与 md 报告一致：`1.1`（未实现）/ `2.3`（实现错误）/ `3.5`（Bug）/ `4.2`（不确定）/ `P1`（已通过） |
| `cat` | 是 | `missing` \| `wrong` \| `bug` \| `unknown` \| `pass` |
| `sev` | 否 | `高` \| `中` \| `低` \| `—` |
| `title` | 是 | 一句话结论，不要带「违反了」这种判断词 |
| `where` | 是 | `文件:行号` 或证据位置，等宽字体展示 |
| `now` | 是 | 代码现在到底怎么做的 |
| `why` | 否 | 影响；`pass` 条目这里写「口径一致之处」 |
| `reqs` | 是 | `[["编号","定稿原文"]]`，至少 1 条；编号必须能在 `spec` 里找到 |
| `check` | 是 | 怎么算通过：可执行、可观察 |

`check` 的正反例：

- 好：「关闭 531 后进装配页：冒险槽出现锁图标；点它弹出解锁条件；军团槽仍可装配。」
- 差：「符合需求。」「需要确认。」

## spec

```json
"spec": {
  "A": ["功能规则（§4）", "R1-1|入口①：装备页两个槽位本身是入口\nR1-2|入口②：建筑默认落抽取页签"],
  "B": ["界面与交互（§5）", "M3-3|箭头染色口径"],
  "C": ["配置与外部依赖（§6）", "CFG-1|五张运行时表"],
  "D": ["多语言文本（§7）", "TXT-2|逐条键位以 §7 为准"],
  "E": ["评审答复与美术（§8）", "QA-10|战力同步刷新"]
}
```

- 每节是 `[节标题, 行文本]`；行文本一行一条，`编号|一句话标题`，用 `\n` 分隔。
- 编号前缀决定分节标签（A=规则 / B=界面 / C=配置 / D=文本 / E=答复），可用其他字母，标签会退化成「条目」。
- 页面会自动把「被 issue 引用的条目」挂上问题徽标；没被引用的显示 `—`。这不是错误，但**若大量条目无人引用，通常是核查没铺开**。

## 自检会拦什么

- 硬错误（不出页面）：JSON 解析失败、`issues` 空、`cat` 非法、缺 `id/title/where/now/check`、`reqs` 空、`reqs` 结构不对。
- warning（照出页面，但要修）：`reqs` 里的编号在 `spec` 里找不到、`spec` 编号重复、`spec` 条目缺 `|` 描述、`pass` 条目没绑需求。

## 重新渲染与增量维护

1. 页面数据已内嵌在 HTML 里（`window.__CHECK_DATA__`）。只拿到页面、没有 JSON 时，用 `extract-check-data.mjs --from 页面 --out check.json` 取回（建议放需求库 `.process/check/` 或与页面同目录）。
2. 改完 JSON 重跑渲染，**slug 不变**，用户此前的勾选与备注继续有效。
3. 只改一条时不必重写全文：改 JSON 里对应条目，重跑一次即可（渲染 < 1 秒）。
